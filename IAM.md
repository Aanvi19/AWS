**IAM Users creation Process**
```
IAM > users > create a username > Provide user access to the AWS Management Console - optional (tick this) > then choose custome password > next > then create a user
Note : we can attached a policy also can create group in which the user will be belongs to
```
**How to create a group**
```
Go to IAM user groups > Create a group name > if you want attached a group policy > then click on the create a group button.
```
**How to create policy**
```
Go to IAM Policies > choose a policy (ex -- ec2,IAM) > Now specify the policies under Actions allowed > then give a name of policy > next >create.
```
**How to create Roles**
```
go to IAM > create Roles > Select trusted entity (aws service)> also choose use case (ec2 ) > next > choose permission policy  > next > give a role name > create Role.
```
